# 等价类划分法

## 什么是等价类划分法

等价类划分法（Equivalence Class Partitioning）是黑盒测试中最常用的用例设计方法之一。它的核心思想是：程序的输入域是近乎无穷的，不可能穷举所有输入；但可以把输入域划分为若干个子集（等价类），同一个等价类中的任意输入对于揭露程序缺陷的效果是等价的。因此只需从每个等价类中选取少量代表性数据作为测试用例，就能以较少的用例获得较高的缺陷检出能力，解决"测试无法穷尽"与"测试要充分"之间的矛盾。

## 有效等价类与无效等价类

- 有效等价类：符合需求规格说明、程序应当接受的合理输入集合，用于验证程序是否实现了规定的功能。
- 无效等价类：不符合需求、程序应当拒绝或给出明确错误提示的输入集合，用于验证程序的容错与异常处理能力。

设计用例时两类都必须覆盖。经验表明，针对无效等价类的用例往往能发现更多缺陷，因为开发人员容易忽略非法输入的处理，常见后果是返回 500、堆栈泄露或脏数据落库。

## 常用划分规则

1. 若输入规定了取值范围（如 1~100），可划分一个有效等价类（范围内）和两个无效等价类（小于下界、大于上界）。
2. 若输入规定了值的个数（如必填、恰好 N 个），可划分有效类与无效类（为空、多于 N 个）。
3. 若输入是一组枚举值，则每个枚举值构成一个有效类，枚举之外的任何值构成无效类。
4. 若输入必须满足某种格式（如手机号、邮箱），符合格式为有效类，每一种破坏格式的方式各为一个无效类。
5. 若需求中包含业务规则（如"用户名全局唯一"），满足与违反规则分别构成有效类与无效类。

## 用例设计步骤

1. 通读需求，列出所有输入参数及其约束条件；
2. 为每个参数划分有效、无效等价类并逐一编号；
3. 先设计用例覆盖有效等价类：一条用例可尽量多地覆盖尚未覆盖的有效等价类；
4. 再覆盖无效等价类：每条用例只覆盖一个无效等价类，避免多个非法输入互相掩盖错误提示；
5. 补充参数组合场景与业务规则相关的用例，评审后去重。

## 示例：登录接口

某登录接口参数为 username（必填，3-20 位字母或数字）、password（必填，6-32 位）。

- username 有效等价类：8 位字母数字组合，如 "zhangsan01"；
- username 无效等价类：空字符串、2 位 "ab"、25 位超长串、含特殊字符的 "zhang@!"；
- password 有效等价类："a1b2c3"；
- password 无效等价类：空字符串、5 位 "12345"、40 位超长串。

据此设计约 8~10 条用例，即可替代穷举，覆盖该接口绝大多数输入合法性缺陷。配合边界值分析法对每个长度边界再补测上点与离点，效果更佳。
